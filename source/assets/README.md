# Assets Directory

This folder is for your images and other assets.

## Profile Image

Add your profile photo here as `profile.jpg` (referenced in [index.md](../index.md)).

Recommended specs:
- Square aspect ratio (e.g., 400x400px)
- JPG or PNG format
- Keep file size under 500KB for fast loading

## Other Assets

You can also add:
- Project screenshots
- Blog post images (reference them in your posts like `![Description](/assets/image-name.jpg)`)
- Icons or logos

Just drop your files here and reference them in your markdown files!
